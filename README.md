# Live Events – Backend Assignment

## ⚡️ Quick Start

```bash
# clone the project
git clone <repo-url> && cd liveevents

# build the project
./mvnw clean package -DskipTests

# start Kafka & Zookeeper via Docker
docker-compose up -d

# run with mock profile (WireMock + Kafka via Docker)
SPRING_PROFILES_ACTIVE=mock ./mvnw spring-boot:run
```

> **Endpoints:**  
> • `http://localhost:8080/events/status` – REST API  
> • `http://localhost:8081/score/{eventId}` – Mocked score API

## 🧩 Design Summary

| Area                | Choice                                          |
|---------------------|-------------------------------------------------|
| Framework           | Spring Boot 3.4.5                               |
| Java version        | Java 21                                         |
| Scheduler           | `TaskScheduler.scheduleAtFixedRate()` per-event |
| Score API           | Async via `WebClient`                           |
| Messaging           | Kafka (`KafkaTemplate<String, ScoreMessage>`)   |
| Error handling      | Fetch/publish wrapped in try/catch with logging |
| Mocking             | WireMock (`mock` profile), port 8081            |
| Tests               | JUnit 5, Mockito, AssertJ, EmbeddedKafka        |
| Build tool          | Maven + Maven Wrapper                           |
| Profiles            | `default` (real API) vs `mock` (local stub)     |
